## Şunu yapmak için
- **Dosya kurmak ya da farkı görmek:** `sunucu/kur.sh fark`, sonra `sunucu/kur.sh kur <repo-yolu>` ya da `kur tumu` (yalnız push'lu main). Yeni dosya `sunucu/kurulum.tsv`'ye eklenir. Elle kurulacaksa önce kurulu özet karşılaştırılır; aşağıdaki `scp` + `install` satırları bu durum içindir. Kurulum belgesi "Kurulum".
- **Kural değiştirmek:** `sunucu/rules/sunucu.md` düzenle → push'lu main → `sunucu/kur.sh fark` → `sunucu/kur.sh kur sunucu/rules/sunucu.md` → `rei.service` restart'ı Yusuf'a sorulur ya da 05:00 beklenir (kurallar oturum başında okunur). Bekleme döngüsü komutuna dokunulursa `sunucu/sbin/rei-mac-izle.sh` deseni de değişir.
- **Telegram eklentisini (fork) değiştirmek:** `sunucu/telegram-eklenti/server.ts` (kart metni: `permissionCard`, `bashBaslik`, `mcpBaslik`; soru: `ask` case'i + `callback_query` `askM`) → inceleme ajanı effort high (izin aktarma = güvenlik sınırı) → `sunucu/kur.sh kur sunucu/telegram-eklenti/server.ts` → `systemctl restart rei`. Yeni dosya `kurulum.tsv`'ye eklenir; bağımlılık değişince `bun.lock` satırı `sunucu/lib/eklenti-hazirla.sh`'yi tetikler. `rei-ping.sh` `dinleme` dosyasına bağlıdır: önce eklenti + restart, sonra ping. Kurulum belgesi "Telegram eklentisi" (üst sürüm farkı, geri dönüş, deney yöntemi).
- **Rei betiği (bin/) güncellemek:** `sunucu/bin/<ad>` düzenle → `scp` → `install -o rei -g rei -m 755 ... /home/rei/bin/<ad>` (uzantısız ad). Kurulum belgesi "Betik güncelleme".
- **Adım kartını değiştirmek:** `sunucu/bin/rei-adim.mjs` (`etiketle` araç→etiket, `kartMetni`) → `sunucu/kur.sh kur sunucu/bin/rei-adim.mjs` (restart gerekmez, her çağrıda yeniden çalışır). Hook girdileri `sunucu/etc/managed-settings.json` → inceleme + `sunucu/kur.sh kur sunucu/etc/managed-settings.json` → restart. Kapatmak: managed'dan `rei-adim` girdilerini sil.
- **Managed settings değiştirmek:** `sunucu/etc/managed-settings.json` → inceleme + supheci (güvenlik sınırı) → `sunucu/kur.sh kur sunucu/etc/managed-settings.json` → `systemctl restart rei` (Yusuf'a sorulur). Çalışan oturum dosyayı kendisi de yeniden yükler: kanca ve izin değişikliği kurulum anında etkiler, kancanın gösterdiği dosya önceden kurulu olmalı.
- **Kapıya yeni alt komut:** `sunucu/vps/rei-kapi` (yeni `case` kolu) → gerekirse `rei-deploy`/`sudoers-rei-deploy` → inceleme (+supheci) → `scp` + `ssh vps 'install -o root -g root -m 755 /tmp/rei-kapi /usr/local/sbin/rei-kapi'`. Rei'nin ask kuralı gerekiyorsa `managed-settings.json`.
- **`deploy-durum`'a proje eklemek (yalnız okuma; deploy kapıya dönmez):** `sunucu/vps/rei-deploy` `case "$proje"` + `sunucu/vps/sudoers-rei-deploy` satırları + `sunucu/vps/rei-kapi` proje regex'i zaten genel; `visudo -cf` ile doğrula; güvenlik incelemesi şart. VPS'te git klonu gerekir.
- **Ziroobank'a yeni izinli uç:** `sunucu/vps/ziroobank-api.py` `IZINLI` (yol regex'i `rei-kapi`'nin `^(/[A-Za-z0-9_-]+){1,6}$` kuralından da geçmeli).
- **Sabah özeti / restart saati:** `sunucu/sbin/rei-sabah.sh`, `sunucu/systemd/*.timer` → `/etc/systemd/system/` + `systemctl daemon-reload`. Deneme: `rei-sabah.sh --kuru`.
- **Yeni bitiş tarihi izlemek:** `sunucu/etc/sureler`'e `YYYY-MM-DD ad` satırı → `sunucu/kur.sh kur sunucu/etc/sureler`.
- **Taramayı değiştirmek:** saat `sunucu/systemd/rei-tarama.timer`, kişi notu `sunucu/etc/tanisma.md`, süzgeç ve model `sunucu/lib/rei-tarama.py`; hepsi `sunucu/kur.sh kur`, `rei.service` gerekmez. ## Akışlar
1. **Rei → ana VPS:** `rei-vps <alt komut>` (`sunucu/bin/rei-vps`) → ssh `Host rei-vps` (`deploy`) → `authorized_keys command=` → `rei-kapi` (`case "$alt"`) → `ziroobank-oku.py` / `ziroobank-api.py` / `sudo -n rei-deploy`.
2. **Deploy:** Claude oturumu projenin kendi yordamıyla deploy eder ya da geri alır (Diskort: vault'taki deploy runbook'u). Rei yalnız okur: `rei-vps deploy-durum diskort` → `rei-kapi` → `sudoers-rei-deploy` → `rei-deploy durum` (HEAD, bekleyen commit, konteyner, sağlık; kurulumun bittiğini kanıtlamaz). `deploy-log` Rei kapısının son günlüğüdür, Claude oturumu deploy'unu göstermez.
3. **Sabah özeti:** `rei-sabah.timer` → `rei-sabah.service` → `rei-sabah.sh` (iki gözcü raporu + `rei-kullanim.py` + disk/RAM + bitiş tarihleri + `sudo -u rei rei-vps sunucu-durum` → `rei-kapi` → `rei-oku` → `sunucu/vps/sunucu-durum.py` + `runuser -u rei rei-sms durum`) → `sunucu/lib/tg-gonder.sh` → Bot API → Kuma `PUSH_SABAH`.
4. **Gözcü raporları:** Mac gözcüsü (kripto-bot, yedekler, kod incelemesi) → launchd `gozcu-esitle.sh` (`~/Yedekler/bin/` kopyası) → `vpn:/home/rei/ZZ/gozcu` → `rei-sabah.sh` okur. Sunucu tarafı (Diskort, Tussle): `rei-gozcu.timer` → `rei-gozcu.sh` → `rei-gozcu.py` (`rei-vps` kapısı → araçsız `claude -p` → rapor → `diskort-incelendi` → imleç) → ACİL ise Telegram; `gozcu-esitle.sh` raporu Mac'e de alır.
5. **Asistan taraması:** `rei-tarama.timer` → `sunucu/sbin/rei-tarama.sh` → `sunucu/lib/rei-tarama.py` (`rei-sms yeni` + bağlayıcı süreci → hassas eleme → araçsız yorum → kod metni kurar) → `sunucu/lib/tg-gonder.sh` → `--onayla`. Sessiz tur yalnız durum yazar, sabah özeti sayıları gösterir.
6. **Ekstre:** PDF Telegram inbox'a → `rei-vps ziroobank-oku` → `rei-ekstre` (`pdf_oku`, `karsilastir`) → özet Telegram'a; satır bazlı finans verisi yalnız sunucuda kalır.

6. **Mac işi (konuşan `is`, donduruldu, yalnız küçük net iş):** Yusuf Telegram'dan küçük net iş → Rei iş notu (`Kota:` satırıyla, sunucuda raporlar dizininde) + özetini Telegram'a → `rei-mac is <proje> [ayar] < not` (ask → onay) → Tailscale → Mac sshd `Match User rei` → `/usr/local/sbin/rei-mac` → worktree + nohup `--calistir` → `caffeinate … claude -p --session-id` (token `~/.config/rei/token`, root `--settings`, `--agents`) → tur biter: son satır `SORU:` ise soru dosyası, değilse bekleme dosyası; push yok, kilit bırakılır → Rei'nin arka plan Bash döngüsü (20 sn, `durum <iş-id>` ilk satır) biter, Rei uyanır → `durum <iş-id>` + `log <iş-id>` (ayraç öncesi) → Mac'in cevabı Telegram'a (ilk tur plan) → Yusuf yazar → `rei-mac devam <iş-id> < mesaj` (varsayılan dışı ayar: `devam-ayar`, ask; `SORU:` varsa Rei `ask`, sonra `cevap <iş-id>`) → `--calistir --devam` → `claude -p --resume` → aynı döngü. Yusuf "bitir" der → `rei-mac bitir <iş-id>` (ask) → kirli ağaç reddi → inceleme izi → `sudo -n rei-push yayinla` (root; sonuç dosyası) → `PUSH: main` (mod main, her yol izinli, korumalı değil, ff) ya da `PUSH: dal` → Rei `rei-mac yollar <iş-id> <sha>`, sonra `rei-mac birlestir <iş-id> <sha>` (ask → düğme) → `ssh rei-mac-onay` → `reionay` → `rei-mac-onay` → `rei-push birlestir` → GitHub ana dalı. Bekleyen iş kilit tutmaz, `iptal <iş-id>` (ask) push yapmadan kapatır. PR yok.
7. **Kod işi:** Yusuf telefondan Remote Control ile Mac'te Claude oturumu açar ya da sürer. Rei bu işi taşımaz: Yusuf'u yönlendirir, gerekirse vault Inbox'ına not bırakır.
